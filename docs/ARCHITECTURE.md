# Architecture

The alpha extraction path is intentionally layered:

```text
Scientific report text
        ↓
Semantic proposal
        ↓
Universal Evidence Schema
        ↓
Deterministic provenance verification
        ↓
Consistency / epistemic alarm engine
        ↓
Universal Evidence Record
```

The proposer is replaceable. Verification and consistency checking are separate
so that a language model is never the sole authority for its own extraction.

Experimental research modules remain available for:
retrieval → study intelligence → RoB 2 → body of evidence → certainty →
challenge → gap falsification.

Those modules require additional validation before promotion into the stable API.
