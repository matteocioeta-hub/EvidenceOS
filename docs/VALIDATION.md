# Validation

EvidenceOS distinguishes:

1. unit/integration tests;
2. development cases;
3. locked blind benchmark cases;
4. publication-grade human-vs-machine validation.

Passing software tests does not demonstrate scientific accuracy.

Development cases currently used to shape Extraction Engine v1:
- Michaelson 2016
- Verbrugghe 2021

A separate 10-RCT blind benchmark has been prespecified. Its primary safety
metrics include provenance accuracy, hallucinated-field rate, critical-error
rate, randomized-sample accuracy, arm reconstruction, outcome mapping, timepoint
mapping, and numeric-field accuracy.

No public performance claim should be made until locked blind Gold records are
scored without post-hoc tuning.
